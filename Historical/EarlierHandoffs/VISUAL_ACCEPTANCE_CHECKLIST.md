# Visual acceptance check — compare on a real iPhone

1. Header displays **Ignition.** in the top-left over the scenic sky, and view controls at the top-right.
2. Background shows the approved detailed sunrise, mountainous green valley, lake, and winding luminous blue path (not flat triangles).
3. Chronological task landmarks display real saved task titles and times. Empty days do NOT display fake scheduled tasks.
4. Blue Now marker is visible immediately above the white foreground sheet at the current time.
5. Small session footprints remain on the day for actual session starts; timer ending alone doesn't label a task complete.
6. White bottom sheet uses compact typography, task title, next action, one large blue **LOCK IN** button and an honest protection-state label.
7. The collapsed sheet immediately meets the small white Now / Plan tab bar; there is NO large empty band between them.
8. Swipe up on sheet expands task list; swipe down collapses it. Panning the scene gives a Back to Now option.
9. Plan opens a functioning calendar and tasks. Focus opens the nighttime full-screen timer; its controls affect the same persisted session.
10. Test 2-minute timer-only fallback and regular 25-minute background timer. For `Ignition-Full`, separately test Screen Time, Lock Screen and Dynamic Island on a signed physical iPhone.

The approved artwork is flattened. The in-app scenery layer is cropped and label-cleaned from it, so the art's original typography and certain small details cannot be pixel-perfect. Do not silently replace it with a new unrelated landscape.
