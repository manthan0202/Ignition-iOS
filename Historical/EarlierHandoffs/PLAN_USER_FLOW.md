# The intended Ignition Plan interaction

**Top area (calendar):** header with day, stable week picker and Today button; vertical day timeline with real-time red Now line; color-coded events and scheduled work; 15-minute scheduling precision; overlaps arranged side by side.

**Divider:** drag downward for more calendar, upward for more tasks; three magnetic resting sizes. The calendar and task list scroll independently.

**Bottom area (tasks):** Unscheduled To schedule list and On this day filter; capture by typing or voice; long-press to pick up a task and drop it into a calendar slot; tap calendar-plus for an accessible time picker instead.

**Event actions:** tap to edit or select for Focus; drag to move; context menu to change time/duration; fixed imported events are read-only.

**Design boundary:** Only the Plan tab changes. The approved Now scenery, floating LOCK IN sheet, nighttime Focus view, Live Activities and existing work flows retain their identity.
